# dsh-prompt-plus

> 非官方 DeepSeek Harness 社区插件，未经 DeepSeek 审核或背书。

在输入框有内容时显示提示词优化按钮，使用当前会话选择的模型改写草稿。优化后可以恢复原文；草稿不会自动发送。

## 安装

```sh
dsh plugin --profile <profile> add github:liaoli-hero/dsh-prompt-plus
```

将 `<profile>` 替换为你的配置名称；安装后重启相应的 Harness 配置。使用前需要可用的模型和服务。插件会把待优化的草稿发送给当前选择的模型服务，调用可能消耗额度。

## 使用

在对话输入框输入草稿，点击工具栏的四角星按钮。完成后可检查改写内容，点击恢复按钮可以还原草稿。出错时插件会提示原因并允许重试。

本插件通过 DSH 的 `conversation.input.left` 槽位接入界面，通过宿主模型服务进行改写。它在 DeepSeek Harness 桌面版 0.2.1-rc.5 的本地环境中开发；跨版本兼容性和全新环境安装尚未独立验收。
